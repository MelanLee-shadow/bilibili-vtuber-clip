# 主播切片标题风格（标题 LLM prompt 实际注入的完整权威）

这份资产是标题 LLM prompt 实际注入的**完整权威**。规则与 few-shot 都以此为准，随维护者手定/授权上传标题与平台生态调研持续迭代。

## agent 首次配置时，问频道主人

- 贴 3–5 条你满意的历史标题（没有就先空着用默认风格跑，出稿后人工定几条再回填）？
- 你讨厌什么味道的标题（哪些词/结构绝对不能用）？
- 标题该围绕什么核心（通常是主播本人的气质/反应，而不是内容摘要）？
- 有没有实证数据支持"哪类词/钩子能提升播放"（如身份/关系类人设词）？量化差距是多少？
- 档案标题与封面嵌字的风格要求是否不同（如冒号结构只能用在哪一处）？
- 发布 envelope 格式是什么（频道前缀怎么加、歌切标题固定格式是什么）？
- 标题长度区间与主力长度带是多少？
- 违禁词/机器味词清单有哪些？

## 核心原则

观众不是因为内容点进来的，是因为**这是【主播名】**才点进来的。标题首要围绕主播本人——她/他的气质、反应、口癖、梗、名字；切片内容只是辅助素材，用来支撑一个"关于主播"的吸引人标题。引人注目为先。

**标题同时是在和粉丝圈对话**：维护者手定标题会复用当场弹幕和其他切片人正在玩的梗句式，并只用圈内正名称呼主播/常客（不用泛用昵称）。起标题时想象读者是已经认识她的老粉，而不是路人。

（真例，李豆沙）7/19 场圈内共用梗句式"你看看现在别人对X都什么印象"被维护者手定标题沿用；圈内正名清单包括 kmx、主包、老李头、奶P、侄女；起标题时想象读者是已经认识她的 kmx。

判别法：把标题里的"主播名/主播/她"换成任何别的主播还成立的，就是失败的内容摘要式标题。

## 题材与梗词优先级（框架：按本频道播放量实证数据排序调整）

统计法：把切片按"是否含身份/情侣/关系类人设词"分组比较中位播放量；若差距显著，该类词汇必须 front-load 到标题第一分句。同理统计标题长短是否影响播放——若无显著差异，说明"长短是伪命题"，抓手强度才是主变量。

- 若切片存在身份/关系钩子，标题**必须把它放进第一分句**，不许把它埋在后半句或让位给陪衬话题。
- 无身份钩子的纯荒诞冷梗类切片通常播放偏低：它们可以存在，但同场有更强钩子的切片应优先，标题也别只剩冷梗。
- 主播的情绪名场面（哭/撒娇/破音尖叫/表白）通常是第二强钩子。
- 粉丝互动题材播放中档但互动率（赞/藏比）最高，是粉丝向保底盘，不按低播放淘汰。

（真例，李豆沙调研，n=69 条谈话切片）标题含百合/身份人设词（百合/侄女/直女/女同/拉拉/女朋友/卖姬/嗑CP/恋姐/坏女人/0.6/谁1谁0/女同事/告白…）的 22 条中位播放 1108，不含的 47 条中位 466——2.4 倍差距；TOP10 有 5 条含身份词，FLOP10 只有 1 条；标题长短几乎不影响播放（短/中/长中位 720/561/529）。无身份钩子的纯荒诞冷梗（灯有没有关系/拜早年/炸学校这类）是实证 FLOP 模式（200-220 播放档）。她的情绪名场面（哭/撒娇/破音尖叫/表白）是第二强钩子（乌鸦叼毛 1699/哭哭表情 1113/哑巴尖叫 905）。kmx 互动题材播放中档但赞藏比最高（花篮 8.6% 赞/播），是粉丝向保底盘，不按低播放淘汰。

## 第零条铁律

**维护者给定的标题正文就是定稿，正文一字不改。** LLM 起标题只用于没有人工标题的场合；`title_llm_call=None` 表示不让模型重写正文，不表示绕过发布门。人工与自动标题最终都走同一个 archive envelope：talk 补 `【主播名】`，song 归一为精确目录式，并验 12–48 字与成对标点。自动标题另外受 selection-hook 与机器味禁词门；人工正文不因这些风格门被自动改写。

## 档案标题 vs 封面嵌字（务必区分）

两处标题风格不同，不要混用：

- **档案标题**（B站视频页标题，带 `【主播名】` 前缀）：可用冒号"引语：反应"结构。下面结构谱系的冒号结构**仅适用于档案标题**。
（真例）"李豆沙第999次澄清：我不是奶皮！"就用了这个冒号结构。
- **封面嵌字**（叠在封面图上的字，**不带** `【主播名】`）：**从不用冒号**！分句用**换行**，不用标点。生成封面向标题时就该干脆短、无冒号，常带主播本人的招牌词/persona 词（代码里做冒号自动转换成换行的钩子）。
（真例，李豆沙）封面嵌字："唱完《旅行的意义》\n才发现伴奏像KTV录的"、"吵闹小李新哭哭表情"、"熊猫头提醒你用电安全"。
- **封面梗字（自动标题封面的默认，若你的频道也走此路线）**：平台高播放切片的封面调研可能显示——高播放封面上的字往往是短小的"梗字"（她的原话/质问/反差点），从不是整条标题。机制：艺术指导 LLM 选出主梗字整行高亮色+可选副行，必须是文案逐字片段；确定性兜底取最后一个 ！/？ 短分句，都没有则回退整段文案。人工手定标题的封面若走独立规则，仍需守"每个成分都不许丢"短句化铁律；歌切封面可保持裸《歌名》banner 的简洁形态（若适用）。
（真例，李豆沙生态调研）B站 20万+ 播放切片封面调研实锤：高播放封面上的字是 2-12 字的"梗字"，如"什么是直女""给我整无语了"。另一案例：人工手定标题的封面不走梗字，仍守"每个成分都不许丢"短句化铁律；歌切封面裸《歌名》banner。

## 结构谱系（按维护者手定语料重排；每种配语料真例）

1. **三拍叙事（主力结构，25–45 字）**：铺垫/事件 → 转折或关键细节 → 点睛（她的原话、吐槽或粉丝视角盖章）。信息给足，让没看直播的观众光读标题就能脑补出完整一幕。
（真例，李豆沙）精心设计MC环节想让kmx用两个字为大家介绍自己，是奶P！才，才不是熊猫呢！／大喊李豆沙是姐姐妈妈宝宝老公主人，观众已见怪不怪了，这就是主包和kmx的羁绊啊／吵闹熊猫头成为哑巴后顿感被吵到，发出好吵的尖叫，可惜已经没人能听到了／熊猫头竟然不知道我去炸学校的完整歌词，只知道一句我去炸学校，谁是卧底不言而喻了！

2. **原话直引 + 拟她口癖**（把她最出圈的那句话直接写进标题，保留说话质感）：结巴、傲娇、拖长音、第一人称自称等口癖类型。引用必须真实出现在切片里，可轻度精炼，不许编造口癖。
（真例，李豆沙）都，都怪你kmx，你看看现在别人对我都什么印象，老李头私下烟酒槟榔都来的（误／熊猫头现场表白到底爱不爱kmx，早就说过很──爱──了!／原来说的是数字零啊，还以为在说李姐我呢

3. **粉丝视角点睛尾**：前段客观讲事，最后一拍切到切片人/粉丝视角的感叹或盖章，像弹幕在说话。可用（误 这类弹幕系收尾。
（真例，李豆沙）……这就是主包和kmx的羁绊啊 ／ ……kmx都是好人！ ／ ……谁是卧底不言而喻了！ ／ ……老李头私下烟酒槟榔都来的（误

4. **名字/词语谐音梗**（优先级很高）
（真例，李豆沙）反沙，不是反李豆沙！／沙豆李沉浸在指认上下左右和疯狂摇头之中（乱序玩名"沙豆李"）／原来说的是数字零啊，还以为在说李姐我呢（李"零"谐音）

5. **栏目/仪式框架**（内容确实是她在"开讲"/固定环节时用）
（真例，李豆沙）豆沙小课堂，侄女究竟应该如何找女朋友呢？

6. **一本正经 + 荒谬**
（真例，李豆沙）"跳闸难道不是把闸搬上去就行了吗？"主播一本正经犯傻／竟敢无视灯！语言学里的经典问题，对"灯有没有关系"这个问题的回答是点头，究竟灯有没有关系呢？／已经7月了，不会打麻将的小李只好给大家拜个早年了

7. **夸张宣言 / 计数 / 嘴硬**
（真例，李豆沙）李豆沙第999次澄清：我不是奶皮！／一个月没直播还嘴硬：我七月其实播了38场！／我在这里是小皇帝？主播突然开始自封了

8. **悬念问句 + 判词**
（真例，李豆沙）试问Hime Hina谁1谁0，吵闹小李直言，这种吵吵闹闹的最难当1了／当拉拉还要本科文凭？主播细思极恐

9. **悬念遮字体**（可选结构，酌情放开）：把标题里**唯一最劲爆的名词**用 ⚪⚪ 遮住制造点开欲。硬规则：被遮的词必须真实出现在切片里；⚪ 个数=原词字数；只遮"敏感/擦边/剧透"性质的词；**绝不遮检索需要的专名与身份词**（这类是搜索入口，必须明文）；同一批切片至多 1 条用遮字，不许成批玩。
（生态真例）"主播你怎么有6个⚪⚪"／怎么会有舰长给主播寄一次性○○啊啊啊啊？？？？
（真例，李豆沙）维护者放开该结构；生态实证来源：南町频道"主播你怎么有6个⚪⚪"27.9万播放。

10. **引语 + 冒号 + 她的反应**（老结构，仅档案标题可用；不再是默认首选——同一场多条切片时冒号结构至多占少数，全批"X：Y"是机器味单一化）
（真例）"晚安主人"现场接梗，主播立刻反杀：虽然不是你的主人／被说开组会来晚了，主播反怼：因为我们还没开始唱

11. **歌切专用**（维护者定的铁律）
    - 格式固定：`【主播名】XX歌，《歌名》`（XX 按你的频道歌切栏目命名习惯定）——《歌名》前后**不加任何字**。
    - 禁止一切后缀/衬词：不要"｜副标题"、不要 hook 尾巴、不要"直播间唱"这类附加语。
    - 谈话切片里聊到歌、唱翻车段按谈话标题规则走（可用《歌名》+反应），但真正的歌切成品标题只有目录式一种。
（真例，李豆沙）格式固定：`【李豆沙】豆沙歌，《歌名》`，真例【李豆沙】豆沙歌，《暖暖》；旧的 `《屑屑》你` 是已废弃 hook 形态，正确歌切发布标题只能是【李豆沙】豆沙歌，《屑屑》。

12. **温柔面（哄睡/晚安类谈话片）**——要具体到唱了什么、怎么个温柔法
（真例）温柔《虫儿飞》清唱甜美哄睡（这是谈话/哄睡片段标题例，不是完整歌切；完整歌切仍只能用目录式）／观众想在直播间睡觉，她细声细气念晚安名单

## 生态参照（结构可参考，词不自动入词库）

来源：在你的平台上搜索本频道相关关键词，比较高播放侧与最新发布侧的标题风格。

高播放标题的共性通常是：引语驱动、事件具体、身份/关系人设词浓，几乎不存在内容摘要式标题。

可借用的生态结构（引用的话仍必须真实出现在切片里）：
- **双引语对话体**：一问一答两句原话直接并置。
- **被迫说出体**：互动环节输掉后被迫说出的原话。
- **重复递进体**：情绪层层递进的重复句式。
- **列举体**：空格分隔的名场面动词串。
- **直呼质问体**：对主播本人直接喊话式质问。
- **"X生涯就结束了"体**：戏谑夸张的身份宣判句式。
- **世界名画体**：拿画面场景类比一幅名画。
- **官方号极短爆点**：官方自切风格，短爆点只在梗足够硬时用，宁可用完整叙事结构也不要硬凑短。
- **当期梗共振**：优先复用当场弹幕/圈内切片人正在玩的句式，梗必须在本切片里真实出现过。

（真例，李豆沙调研；来源：李豆沙_Channel 官方号高播放标题、第三方切片人高播放标题、7/19 线下场当期切片）双引语对话体："我们柚恩也是女同，能和柚恩联动吗？""柚恩她自己知道吗！"；被迫说出体：塔神互动环节输给天走人，被强迫说出"我最不喜欢吃椰子鸡了"（当日播放最高之一）；重复递进体：控诉东爱璃，太可恶了，坏女人，太坏了！／南町是最最最喜欢；列举体：道歉 跳脸 撒娇 嗦面；直呼质问体：李豆沙你真是铝铜吗（"铝铜"=谐音梗）；"X生涯就结束了"体：对联动对象叫了别的女人的名字直女生涯就结束了吗；世界名画体：世界名画：同事们在团建，李豆沙无人问津；官方号极短爆点（李豆沙_Channel 自切风格，播放上限最高）：要来kiss kiss吗／你 不 许 玩 谐 音 梗／白河galgame不是这样的！！；当期梗共振：7/19 场"你看看现在别人对X都什么印象"多家共用，维护者手定标题同款。

## 高频词库（气质抓手；框架）

维护者/运营在此积累一份"她的口头禅/气质词"清单，用于标题措辞库；**词库来源铁律**：只允许收录经维护者已上传/手定标题验证过的词；生产线机器生成的旧标题不是语料，即便其中混入了听起来顺口的词也不能反向倒灌词库；生态调研里别家切片的词同样不入词库，只借结构。扩词先对照已上传标题核对。

（真例，李豆沙）高频词：直呼、甚至、终于、大大方方、反向、到底、万一、早就、只好、一定要、太…了、瘾来了、假装不知情、逆出道、没有边界感、奇遇记、精选辑、试问、究竟、竟敢、见怪不怪、不言而喻、羁绊、第一次、精心设计、大喊、顿感、可惜、连声、拱（弹幕拱她）、嘴硬。
（真例，李豆沙）专属名词：李豆沙、豆沙、小李、李姐、老李头、沙豆李（乱序玩名）、主播、主包、熊猫头、奶P、侄女、kmx、长沙话、22966160（直播间号自称）；口播"kimo熊"成品一律写 kmx，专名永远用圈内正名。详见 assets/lidousha/persona.md 与 glossary.txt。

## 硬性规范

- **发布到平台的标题一律加频道 envelope**：talk 为 `【主播名】` + 正文；song 必须**精确**为 `【主播名】XX歌，《canonical歌名》`（XX 按你的频道歌切栏目命名习惯定）。构思/override 资产可只存正文，投稿时由共享 choke point 规范化；维护者定稿正文逐字不改。字数按最终含前缀计。
（真例，李豆沙）envelope 实例：talk 补【李豆沙】；song 精确为【李豆沙】豆沙歌，《暖暖》。旧的 `《屑屑》你` 是已废弃 hook 形态，正确歌切发布标题只能是【李豆沙】豆沙歌，《屑屑》。
- **长度（按你的手定语料统计重定）**：含前缀 12–48 字；主力带 25–45 字的完整叙事结构（可参考维护者手定标题中位数约 35 字）。梗足够硬的短爆点可以短到 12–20 字；不要为了凑短把梗和信息压没，也不要注水凑长。
- 口语化、有画面感；？！制造悬念与情绪；（误 等弹幕系收尾可用。
- 引号引她的原话或弹幕原话；冒号引出反应/后半句（仅档案标题，且不要整批用）。
- 标题里引用的话必须真实出现在切片里（可轻度精炼，不许编造）。
- **维护者定稿标题的每个成分都是有意的，封面短句化时一个都不许丢**（数字/房间号/自称类成分照搬原样；ASCII 串是排版原子不拆行）。
（真例，李豆沙）封面漏掉"22966160"被指正——那是直播间自称，是标题有机部分。
- **讨论某部作品的切片，标题必须带上《作品名》**（维护者定：作品名从转写/弹幕确证，不许猜）。
- **关联作品即出**：切片内容与某作品**相关**就要在标题里显示出来——不限于"讨论作品"，包括间接关联（如队友 ID 是某作品人名组合、玩梗引用、角色名出现等）。关联作品名是检索入口与身份/关系受众的钩子；关联证据从画面/转写/弹幕确证，不许猜。tag 同步出（见 upload_tag_policy 对应 rule）。

## 违禁词（LLM 自动标题命中即重写，仍不合格则打 flag 保留）

**6 个空洞标题党词，一律禁用（作为独立词）：炸裂 / 震惊 / 天花板 / 绝了 / 犯规 / 太顶。** 这类空洞夸张词维护者不喜欢。

**机器味弱化/强调词全局禁用（维护者定）**："直接""当场""秒X"（秒懂/秒回…）一律不出现——维护者的真实历史标题里从来没有这些词。写她具体做了/说了什么、引原话、用梗词。代码硬门 `_TITLE_BANNED_FILLER_WORDS`+`_TITLE_BANNED_MIAO_RE`。

**离谱是两用词**：描述性的"越看越离谱 / 越整越离谱"是维护者认可的结构，可以用；只有空洞的 **"X到离谱"后缀式**才禁。

更禁 **"X到犯规/炸裂/离谱"这种万能后缀**——它把任何东西都套成夸张，却不说清到底发生了什么。标题必须**具体到发生了什么**。
