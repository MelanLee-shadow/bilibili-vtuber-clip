# 主播 persona（标题/封面/语义裁决共用）

## agent 首次配置时，问频道主人

- 身份一句话（平台/分区/房间号/内容特色）？
- 形象要点：标志性视觉特征是什么（发色/耳朵或其他部位装饰/衍生形象名）？这个特征是"长在身上"的设定还是外部可拆卸装饰？封面绝对禁止画错、禁止私自添加什么？
- 联动/多人场景中，封面主体是否必须锁定主播本人、不能画成同台其他人？
- 地域/方言特色？
- 粉丝文化：有没有专属粉丝梗称呼（自称/常客称呼/黑话）？
- 性格气质里标题最常抓住的抓手有哪些（口头禅、反应模式、招牌翻车点）？
- 常见切片场景类型有哪些？
- 相关人物/专名维护在哪张表（一般是 glossary.txt）？

## 形象与封面铁律（框架，具体特征见下方示例）

- 形象：【标志性视觉特征，如发色+耳朵/角/尾巴等衍生装饰】（若是"长在身上"的设定特征，要说明"不是"外部头套/帽子，避免出图时被误画成配饰）；衍生/Q版形象叫【小名】；封面里主播本人必须是视觉主角。
- 封面形象铁律（维护者定）：**必须以主播当场直播的实际人物形象为原型**，只允许改动作、表情或 Q 版萌化；**严禁添加帽子、头饰、额外服饰或装饰品**（除非是她本人既有的标志性特征）；联动/舞台/多人场景中封面主体必须锁定主播本人，绝不能画成同台他人。

（真例，李豆沙）形象：虚拟熊猫少女——白发+头顶自带小熊猫耳（长在头上的耳朵，不是熊猫头套/帽子；"熊猫头"只是粉丝外号）。衍生形象"小李/吵闹小李"，有新哭哭表情；封面里她必须是视觉主角。
（真例，李豆沙，维护者定的封面形象铁律）必须以李豆沙当场直播的实际人物形象为原型，只允许改动作、表情或 Q 版萌化；严禁添加帽子、头饰、额外服饰或装饰品；联动/舞台/多人场景中封面主体必须锁定李豆沙本人，绝不能画成同台他人（如142）。

## 地域/语言特色

- 地域：记录主播的地域背景与直播中会切换的方言。
（真例，李豆沙）湖南长沙，直播里会飙长沙话/湖南话。

## 粉丝文化与性格气质

- 粉丝文化：记录频道内部的粉丝梗称呼、老观众/常客的专属点名方式（完整清单维护在 glossary.txt）。
（真例，李豆沙）粉丝梗"侄女/侄女卖姬"；老观众 kmx 常被点名。

- 性格气质（标题最常用的抓手）：列出主播身上反复出现、能撑起标题的反应模式类型——例如反应剧烈的名场面、一本正经犯傻的反差萌、嘴快爱吐槽、口头禅/谐音梗翻车、才艺环节认真与翻车的反差、对观众展现的温柔一面。
（真例，李豆沙）反应大：容易破防、当场看傻、被吓到连喊"好可怕"；一本正经地犯傻：认真讲歪理（"跳闸不是把闸搬上去就行了吗"）；嘴快爱吐槽：看图/看弹幕连环快嘴点评（"一眼AI 好吧"）；爱玩谐音/绕口令并翻车（反沙/反杀/翻砂）；唱歌认真但常翻车忘词，翻车后自嘲笑场；温柔面：哄睡、晚安名单、对观众细声细气。

列出典型内容类型，作为选题/标题参考。
（真例，李豆沙）看AI图连环吐槽、弹幕接梗打闹、讲宿舍/日本生活故事、唱歌（完整歌走歌切流程）、绕口令/谐音翻车。

## 封面表情/角色映射（AI 封面 art-direction 用）

- 默认表情基调：选一个符合主播人设的基调（如清纯软萌/元气/机灵鬼怪等），并说明她被欺负/挑衅时惯常的反应姿态。
- 次要表情：仅当切片角色需要时使用的备用基调，说明与默认基调的差异，不是默认。
- 角色状态→表情映射：为主播常见的反应状态（如破防/看傻/吃醋/嘴硬/一本正经犯傻/哭/温柔）各自定义一个具体的封面表情描述。
- 硬禁止：列出该主播绝不能出现的表情/气质。
- 外观：肤色/服装/发型/配饰一律照该切片参考帧的真实样子；如果主播每场造型不同，不要锁定某一套服装。

（真例，李豆沙，示范格式颗粒度）
- （真例）默认表情：清纯邻家女同学 / 软萌，被欺负但会软软回嘴（shy-but-bites-back）；小闭嘴微笑，不咧嘴。
- （真例）次要表情（仅当切片角色需要）：机灵鬼怪 / 得意（clever-smug，闭嘴坏笑挑眉）——不是默认。
- （真例）角色→表情：破防/被吓=瞪眼张嘴倒吸气+手抬到脸边；看傻=呆滞圆眼小O嘴；吃醋=鼓腮嘟嘴；嘴硬=不服气鼓腮；一本正经犯傻=死板认真脸；哭=夸张可爱哭脸；温柔哄睡/清唱=眼神柔和轻声。
- （真例）硬禁止：永不吐舌头（never tongue-out）、不油滑、不挑衅、不性感、不媚。
- （真例）外观：肤色/服装/发型/配饰一律照该切片参考帧的真实样子，不锁定某一套服装（她每场不同）。
