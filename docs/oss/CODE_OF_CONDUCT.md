# 行为准则

**适用范围：只管本仓库的协作空间**——issue、PR、discussion、代码评审这些
发生在本项目 GitHub 空间里的互动。

**不管辖**：任何人用本软件制作的切片内容、B 站上的任何行为、任何主播/
切片频道/评论区的纠纷。这些发生在 B 站，归 B 站平台规则管——维护者对
站外行为既无权限也无处置手段。**若某个切片内容侵害了你**（无论你是主播
本人还是观众），请直接使用 B 站的举报/申诉渠道向平台反映，那才是有执法
权的地方；向本仓库反映不能解决站外问题。

在本仓库空间内：

- 尊重所有参与者；不接受骚扰、人身攻击与歧视性言行（参照
  [Contributor Covenant](https://www.contributor-covenant.org/zh-cn/version/2/1/code_of_conduct/) v2.1）。
- **不要张贴任何主播或观众的隐私信息**（真实身份、联系方式、未公开行程等）
  ——包括以 bug 报告或讨论为名附带。
- 针对具体频道的内容纠纷（"某频道切了我不想被切的内容"）不属于本仓库
  议题，相关 issue 会被关闭并指向平台渠道。

执行手段仅限仓库内：删除违规内容、锁定讨论、禁止参与本仓库，由维护者
裁量。仓库内的违规可在对应处指出，或用 GitHub 的 Report abuse。
