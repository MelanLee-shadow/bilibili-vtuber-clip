# GPT-6 流水线模型选型（2026-09-25）

## 结论

生产质量默认改为 **`gpt-6-sol`**，并保留每个阶段原有的 reasoning effort：普通字幕首轮仍为
`low`，复杂裁决、终审、标题和封面继续使用各自已有的 `medium` / `high`。只验证 CPA 是否可用的
健康探针改为 **`gpt-6-luna` + `low`**。`gpt-6-astra` 不再作为默认模型，也不在 Sol 失败后自动
升级；它只允许在另有明确授权的单次高价值实验中显式点名。

这不是单纯按官方价格表降档。冻结六片实测中，Sol low 同时取得最低参考距离、最低有效内容
延迟和明显较低成本，是质量、速度与成本三项的 Pareto 选择。Luna high 虽然最便宜，但更慢，且
出现过一次 408 后依靠既有有界重试才成功；它适合轻量探针，不适合默认承担字幕正文。

机器可读汇总见
[`evidence/2026-09-25-gpt6-model-selection-summary.json`](evidence/2026-09-25-gpt6-model-selection-summary.json)。

## 方法

- 复用 2026-09-09 Astra 对照中的六个冻结切片和完全相同的首轮提示词。
- Sol low、Sol medium、Luna high 通过生产 `llm_via_cpa.sh` 与真实 CPA `/responses` 路线现场回放；
  顺序按切片轮转，避免固定先后顺序偏差。
- 生成阶段看不到人工参考；模型响应写盘以后才读取人工批准字幕评分。
- Astra 不重复烧一次同样的六片：使用同一冻结提示词已有的 low/medium 回执作为基线；当时 Astra
  还处在既有 usage-limit backoff，重跑既昂贵又不会改善配对设计。
- 主质量指标 `D_keep` 是输出到人工批准参考字幕的 Levenshtein 距离，越低越好。它与延迟、合同
  成功率、真实 usage token 和按官方单价计算的费用一起判断；它不能代替最终人工/声学门。
- Luna 使用 `high` 是有意给它较有利的质量设置；即使如此，它仍没有在总体质量或速度上支配 Sol low。

相对 Astra low，Sol low 的 `D_keep` 下降 2.19%，平均/总延迟下降 43.07%，本组六片估算费用下降
81.46%（约便宜 5.39 倍）。Sol low 也优于 Sol medium：距离低 4、延迟低 27.25%、费用低
21.59%。因此没有理由把普通字幕首轮统一抬到 medium。

Luna high 的费用比 Astra low 低 98.41%，但总延迟反而高 32.72%，且一次请求先返回 408。
它的低价非常适合探活；用于正文时，为获得接近质量所付出的 reasoning/输出长度和重试延迟抵消了
“轻量模型应更快”的直觉。

## 路由规则

| 工作类型 | 新模型 | effort 原则 | 原因 |
|---|---|---|---|
| 普通 `correct=cpa` 字幕首轮 | `gpt-6-sol` | `low` | 六片实测最佳综合结果 |
| 语义裁决、终审、标题、封面、结构化证据 | `gpt-6-sol` | 保留调用点现有 `medium/high` | 本次只换模型，不借迁移降低推理预算 |
| CPA 健康探针 | `gpt-6-luna` | `low` | 不裁决内容；最低费用与快速小请求足够 |
| Astra | 无默认路线 | 仅显式单次 | 不自动放大费用/延迟，也不把故障变成昂贵 fallback |

模型身份属于 provider contract 和缓存身份。迁移同时更新了 wrapper 默认、所有当前质量调用点、健康
探针、测试 fixture、provider-contract hash 与 cache identity；旧 Astra 回执仍保留原历史身份，不会
伪装成 Sol 缓存命中。新增回归扫描禁止当前生产源码重新引入隐式 Astra 路由，但保留命名明确的历史
Astra 评测工具。

## 官方价格与外部依据

2026-09-22 的 OpenAI GPT-6 Sol/Luna 公告列出的每百万 token 单价为：Sol 输入 $2、输出 $10；
Luna 输入 $0.10、输出 $0.50。Astra 公告列出的单价为输入 $10、输出 $50。三款都支持缓存输入
折扣；本报告按 usage 数据中实际 cached tokens 分开计价。

## 边界

本轮直接覆盖的是中文谈话字幕首轮，不把六片结果夸大成所有视觉/标题任务的通用排行榜。因此，
复杂阶段只替换为 Sol、保留原 effort 和所有 fail-closed 门，而不是统一降到 low 或 Luna。六片中所有
模型对显式人工修改的 exact 命中仍为 0；这说明模型选型不能取消 CPA 后的声学、人工真值、mutation
及最终字节验收。后续若要把某一高 effort 阶段降级，必须用该阶段自己的冻结样本另做配对测试。
