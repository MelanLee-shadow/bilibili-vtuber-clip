## 四、标定观测（**只记录，没有据此改任何常量**）

N=10 全部 1382 个过 VAD 的窗口的 CAM++ 最佳-prototype 相似度分布：

```
p05    p10    p25    p50    p75    p90    p95    p99
0.014  0.049  0.145  0.286  0.555  0.668  0.701  0.741
```

分布是**双峰**的，谷底大致在 0.31–0.45；落在当前 abstain 带 [0.31, 0.50) 的
原始窗口只有 215 个（15.6%）。但逐候选的 `unknown_share` 普遍到 0.25–0.42，
差额来自两处，都要记在案：

1. **平滑降级**：孤立单窗被最短持续时间约束降成 UNKNOWN（276 − 215 = 61 个）。
2. **50% 重叠窗的时长记账**：孤立窗覆盖 2000ms，而连续段里每多一窗只增加
   1000ms。于是**散落的 UNKNOWN 被系统性地按两倍权重计入** `unknown_share`，
   `host + other + unknown` 之和会超过跨度真实时长。方向是偏向 abstain
   （fail-closed 安全侧），**看到结果之后不改它**；根治方向是按 hop 大小的
   切片单一归属（每个 1000ms 切片只归一个标签），留给下一轮由 Ivan 裁。

若按 Pro 的 `t_H = Q_0.995(s | non-host)` 取阈值：两条"主要发言人不是李豆沙"的
候选，其窗口分数 p95/p99 分别是 0.467/0.536 与 0.541/0.768 —— 都**高于**当前
`t_H = 0.50`，即按 Pro 的判据当前 t_H **偏松**。但同一批数据里，Ivan 说该发的
`auto_223750_578_654` 的主播语音窗口分数是
`0.406 0.415 0.416 0.416 0.457 0.475 0.477 0.483 0.501 0.505 0.522 0.524 0.581 0.590 0.625 0.666 0.666 0.673 0.726 0.739`
—— **横跨 0.50**，抬高 t_H 会把她自己的话推进 abstain 带。

**两个分布在 [0.35, 0.55] 真实重叠。** 这正是 Pro 自陈「最没把握」的那一点在
本域内被实测证实：现成 CAM++ 短窗余弦，用这套 3 条 / 167.69s 的 enrollment，
在李豆沙的游戏直播音频上没有一条干净的分界线。样本量（4 条候选、无干净标注）
**不足以**按 Pro 的分位数法定阈值，所以本轮不定。
