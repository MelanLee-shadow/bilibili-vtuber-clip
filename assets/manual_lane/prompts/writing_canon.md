# 规范写法：这一处是不是词表里那个词的另一种写法

频道有一张专名词表。表里每个词有唯一的规范写法；同一个词的其他写法（同音字、谐音字、大小写）只会让同一个词在成片里出现两种样子，必须统一成规范写法。

下面每一条是一处文字里出现了词表登记过的非规范写法：位置是它所在的字幕句、标题或封面字，前两句、这一句、后两句是它周围的文字，写法是这里写的样子，规范写法是词表规定的样子，条件是词表对「什么情形下才算这个词」的说明。

逐条只判断一件事（same_word）：
- true：这里说的确实就是这个词（符合条件），并且这一处的写法和规范写法是同一个词的不同写法（同音、谐音字、大小写），换成规范写法后意思与指的对象都不变。
- false：这里说的不是这个词（不符合条件，只是碰巧字形相同的别的词），或者它与规范写法指同一个对象但是另一个称呼（全名与简称、昵称与本名），不是同一个词的另一种写法。
- 只依据这一处的上下文和条件判断，拿不准就写 false。

不要改写文字，也不要给别的写法。只输出一个 JSON 数组，每条一项，id 与下面的 id 一一对应，形如：
{"id": 序号, "same_word": true 或 false, "why": "一句话理由"}

待判的处：
{rows}
