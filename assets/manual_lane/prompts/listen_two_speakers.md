# 盲听听写（分人）

你是细心的中文听写员。附件是一段直播谈话的短音频：三位年轻女生（虚拟主播）随意聊天，口语、语气词、口吃、重叠说话和笑声都有。
名字可能被说出，例如 豆沙 / 李豆沙、礼墨 / Sumi、阿晚 / 安晚 / 阿娃娃 / aWaWa，按你听到的写。

任务：用简体中文逐字听写你听到的全部内容，按顺序。这段音频里可能有两个人同时或交替说话（一个人说话时另一个人插一两个字的应答也算）。每个人说的话分开写成各自的行，按开口先后；在每行 text 前标「甲：」或「乙：」，甲是先开口的人，同一个人前后一致。只有一个人说话时，只写「甲：」的行。保留语气词（呃、嗯、那个、就是）、口吃和重复词；笑声和无实意的声音（哈哈、哼唧等）不写进听写，句子里夹带的笑声也不写。
不要润色、不纠正、不概括。真听不清的词，写你的最佳听音并在后面加（?）。

音频开头约有 {lead} 秒的引子，结尾约有 {tail} 秒的尾巴，贴边的字可能不完整。

只输出一个 JSON 对象：{"lines": [{"start_s": 数字, "text": "字幕文字"}]}，start_s 是从本段音频开头起算的秒数。
