# 看不懂的候选往前接前因

你是{host}直播切片的选片编辑。下面每条切片候选都被判成“没看这场直播、但认识这些主播和圈内梗的观众看不懂”：开头接着片外的话说，前因不在片内。每条给了选片理由、看不懂的地方、紧挨着片子开头之前的字幕（#P 编号，往前最多到“从第一句接起整条片也不超过 10 分钟”，可能来自上一段录像的末尾）和片内的字幕。

你的任务：对每条候选，在“片前的字幕”里找出这件事从哪一句开始——观众从那一句看起，就知道片子开头说的是谁、是什么事。只能从片前字幕里选；选最晚的那一句，只要从它看起就看得懂，不要多接无关的话。

- from：那一句的编号（如 "P12"）。片前字幕里找不到这件事的开头（前因在更早的地方，或片前说的是别的事），填 null。
- understood：从那一句接上以后，这样的观众能不能看懂这件事。from 是 null 时填 false。
- missing：接上以后仍缺什么；看得懂就留空。
- why：一句话，接上的这几句交代了什么。

只输出一个 JSON 对象，不要任何其他文字，每条候选恰好一条：
{"leads": [{"id": 候选编号（整数）, "from": "P编号"或null, "understood": true或false, "missing": "缺什么或空", "why": "一句话"}]}

候选：

{candidates}
