# 导入字幕的低把握句：读法不同会不会改变意思

下面每一条是一份已定字幕里标为低把握的句子：text 是采用的写法，alternatives 是制作人记下的备选写法（可能为空），context 是这句前后的字幕。

只判断一件事（affects_meaning）：如果真实说的是备选写法，或者是与 text 不同的别的写法，这句话的意思会不会改变。
- 只差语气词（嗯、呃、啊）、口吃重复、标点、同义的说法：false。
- 人名、作品名、数字、动作、对象、态度或是否定有不同：true。
- 拿不准：true。

不要改写字幕，也不要判断哪个写法对。只输出一个 JSON 数组，每项形如：
{"id": "句子 id", "affects_meaning": true 或 false, "reason": "一句话理由"}
