# 同一晚同一件事的候选归并

你是{host}直播切片的选片编辑。下面是同一场直播里选出来的切片候选，按直播时间先后排列；每条给了开始时间、选片理由（这一条的看点）和最关键的那几句。各段录像是分开选的，选的时候互相看不到，所以同一件事、同一个梗可能被选了不止一次。

你的任务：找出看点是同一件事的候选，归成一组；一组以后只做成一条切片，归错了会把两条各有看点的片并成一条，少出一条片。只按给出的看点判断，不要猜片子里别处还说了什么。

先看每条的看点是哪个说法：选片理由和最关键的几句合起来，对某个人、某段关系、某件事下的那个结论、定性或称呼（比如“谁是谁的什么”、一个外号、一句给她的定性）。两条的关键句字面不同，说法也可以是同一个。归成一组的条件（满足一条即可）：
1. 后一条的看点是前一条那个说法又接着说：同一个结论、同一个定性、同一个关系认定被重新拿出来争、往下推，后一条的笑点就是前一条那个说法的延续。
2. 后一条的看点和前一条是同一个说法又说了一遍：观众看了前一条再看后一条，会觉得“这个跟刚才那个一样”。

不算同一件事的：
- 两条只是同一个背景（同一个游戏模式、同一个误会、同一个话题方向），看点各说各的：比如同一局游戏里，一条的笑点是她被队友坑了以后的抗议，另一条的笑点是她被人说了一句评价，两条不是同一个说法，就是两件事；
- 同一段对话顺着聊下去聊到的下一件事（紧挨着的两条各有各的落点）；
- 同一种情况又发生了一次：又一回合、又一次互相攻击、又一次被提醒同一条规则，每次有自己的经过和落点，就是两件事：“又说了一遍”指的是同一个说法本身被再拿出来，不是同一种情况再出现；
- 只是出现了同一个人、同一个名字、同一只猫、同一种动物；
- 只是同一类情绪或同一类互动（都是撒娇、都是被调侃、都是下禁令、都是争宠）；
- 只是都发生在同一场直播、同一个游戏里（同一个游戏里先后两次失败、两次缺钱，是两件事）。
拿不准就不归。

每条候选至多属于一组；一组至少两条。没有可归的就回答空数组，这是完全正常的答案。

只输出一个 JSON 对象，不要任何其他文字：
