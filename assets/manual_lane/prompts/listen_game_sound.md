# 字幕里的外文和数字是谁发出的

附件是一段直播原音。直播间里可能有人说话（主播、连麦的人），也可能有游戏、软件或视频自己放出的声音（播报员、倒计时、系统提示音、角色语音），还可能有背景音乐。
窗口开始有约 {lead} 秒引子，结尾约 {tail} 秒尾巴；中间那段对应的字幕是：

「{text}」

按字幕原来的顺序把它切成几段，逐段判断是谁发出的：
- person：直播间里的人说的，包括她跟着游戏念、跟着倒数、读屏幕上的字；
- game：游戏、软件或视频自己放出的声音，直播间里没有人说这几个字；
- unsure：听不出来。
同一段里既有游戏声、也有人跟着说出这几个字时，写 person。
每段原样抄写字幕里的字，不改字、不补字、不漏字；start_s 是这一段在附件里开始的秒数。
只输出 JSON：{"lines":[{"source":"person","start_s":0.0,"text":"字幕里的这一段"}]}。
