# 外部指称（定字幕之前，读识别底稿）

下面是一条直播切片的识别底稿（机器听写，可能有错字、同音字），每句前面是编号。主播说话时常会提到底稿自己没有交代的东西：
作品、角色、人名、圈内的企划或事件；或者引用、模仿、化用一句现成的话（流行语、梗、台词、歌词、别人的名句）。
这些地方机器最容易听错，后面定字幕、写标题都需要知道它们指什么。

频道基本事实（已知的，不用列）：
{persona}

请列出底稿里指向底稿之外、而底稿和上面的基本事实都没有解释的指称，最多 {max_terms} 个。优先列：
- 读起来不通、像是把一个专名或一句现成的话听错了的地方；
- 主播明显在引用、模仿、化用别处说法的地方；
- 没交代是谁、是什么的名字。
普通的词、主播自己的日常叙述、基本事实里已有的名字不要列；念弹幕、感谢礼物时提到的观众昵称也不要列（它们由直播间的记录核对，不靠检索）。没有就让 references 为空数组。

每一项：
- term：底稿里的原样写法，逐字照抄（有错字也照抄，用来定位）；
- cues：它出现的句子编号；
- kind：作品 / 人物 / 圈内事件 / 现成说法 / 其他；
- why：为什么觉得它指向底稿之外的东西；
- likely：你认为它本来是什么（规范的名字，或那句话的原样）。这只用来检索，拿不准就写空字符串，不要硬猜。

只输出一个 JSON 对象，不要任何其他文字：
{"references": [{"term": "", "cues": [1], "kind": "", "why": "", "likely": ""}]}

底稿：
{lines}
