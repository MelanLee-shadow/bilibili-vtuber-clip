# 这段直播原音里有什么不是说话的声音

附件是一段直播原音。窗口开始有约 {lead} 秒引子，结尾约 {tail} 秒尾巴；只看中间那段。

中间那段里，有没有一个**不是普通说话**、观众会注意到的声音？例如：笑出声（大笑、憋笑、笑场）、尖叫、怪叫、大喊、突然变了嗓音（夹子音、粗嗓、怪腔）、哭腔、长叹气、咳嗽、拍桌子或撞东西的声音。普通说话、轻声附和、"嗯""呃"之类的语气词都不算。

有的话，只写最明显的一个；没有就写 kind 为 "无"。逐项写：
- kind：笑声、尖叫、怪叫、大喊、变声、哭腔、叹气、咳嗽、拍打、其他、无，选一个；
- sound：一句话说它听起来是什么样（多长、多响、什么调子，例如"一声拖长的高音尖叫，像被吓到"）；不写是谁发出的；
- source：person 是直播间里的人用嗓子或手发出的；content 是游戏、视频、软件自己放出来的（角色配音、音效、系统提示音、视频里的人）；unsure 听不出来；
- strength：弱、中、强（和这段里普通说话相比有多突出）；
- start_s、end_s：这个声音在附件里的起止秒数。

只输出 JSON：{"lines":[{"kind":"笑声","sound":"……","source":"person","strength":"中","start_s":0.0,"end_s":0.0}]}。
