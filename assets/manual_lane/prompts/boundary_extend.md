# 边界扩展

你是{host}直播切片的边界审查员。上一步已经判出这段故事的完整起止（cue {story_start}–{story_end}），它只有 {story_seconds} 秒，不到成片要求的 {min_seconds} 秒。你的任务只有一件：看故事紧挨着的前后两边，有没有和这件事是同一件事的真实互动，可以并进来。

只有这几类算同一件事：引出这件事的前因或触发，对它的追问、回应、反驳，回扣它的同一个说法或笑点，接着它的梗。
不算同一件事的一律不并：沉默；另一件事（下一个新问题、新的游戏回合或操作、另一条 SC、谢礼、选歌、和这件事无关的闲聊）。并进来的部分必须和故事首尾相接，中间不能隔着另一件事。

不要为了凑够 {min_seconds} 秒而并。两边都没有同一件事的内容，就照实回答“不并”——这条片不会因此被丢掉，它会照样留着，和同一晚同题材的片段合成一条合集，或停下等人看。

每一边如果并，给出新的起点（前边）或终点（后边）的 cue 号，并从新并进来的那几句里逐字摘一句最能说明它和这件事相连的原话（link）。新的起止只能落在下面给出的字幕里，并且和故事的起止一样必须落在句子边界，落在半句话上的不并；link 至少 {link_chars} 个不同的字，笑声、语气词这类哪里都有的话不算。摘不出这样一句，就是不该并。

只输出一个 JSON 对象，不要任何其他文字：
{"before": {"start_cue": 整数或 null, "link": "新并进来的句子里的原话，不并写空字符串", "why": "一句话"}, "after": {"end_cue": 整数或 null, "link": "新并进来的句子里的原话，不并写空字符串", "why": "一句话"}}

输入：
- 故事：cue {story_start}–{story_end}，{story_seconds} 秒
- 选题理由：{hook}
- 关键句（cue 号 原话）：
{peaks}
- 字幕上下文（序号 时间 文字；故事前后各约 {min_seconds} 秒）：
{context}
