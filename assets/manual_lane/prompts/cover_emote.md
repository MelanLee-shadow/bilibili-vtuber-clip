# 封面主表情包按句意选（第 6 步）

封面的一个做法是拿官方表情包当主人物。下面是可用表情包的说明（编号、名字、画面、适合的场景），请读封面字和这段故事
的情绪，选出情绪与封面字那一刻最对得上的表情包。只按说明里的“画面”和“适合”对照句意，不按字面关键词凑；
没有一张真正对得上就不选，不要勉强。

封面字：{lines}
封面字对应的原话：{quotes}
这一刻的表情与动作：{expression}；{action}

可选表情包：
{entries}

只输出一个 JSON 对象：
{"choices": ["最合适的编号", "次合适的编号"], "reason": "一句话说明为什么这张的画面和适合场景对得上封面字的情绪；一张都不选时说明原因"}
choices 按合适程度从高到低，最多 3 个，只能用上面的编号；一张都不合适就写空数组。
