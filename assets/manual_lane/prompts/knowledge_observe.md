# 知识图观察（一条切片封存之后）

下面是一条直播切片的最终字幕（每句前面是编号；带方括号标签的是说话人）、这条片的弹幕和醒目留言，以及频道知识图里已有的条目和它们的各种写法。观众对她的叫法常常只出现在弹幕里（字幕是识别器听到的，可能听错）。
请找出这条片里出现、而知识图还没有的名字：

- `alias`：知识图里已有的人、团体、作品等的另一个叫法（昵称、简称、外号、粉丝对她的称呼）。`of` 填它属于的条目 id。
- `entity`：知识图里还没有的人、团体、企划、事件、作品、角色、游戏、社群或圈内词条。

知识图里已有的条目（id：各种写法；已有的写法不要再写）：
{known}

要求：
- 只写字幕或弹幕里看得出来的，每一条都要有原句为证；quotes 逐字抄自一句字幕或一条弹幕，不改字，而且要包含这个名字。
- `alias` 要能从字幕或弹幕看出它指的就是那个条目（比如字幕里对着主播叫这个名字、说明这是谁的外号，或弹幕、醒目留言对着主播用这个名字跟她说话）；只是读音像、看不出指的是谁的，不写。
- 普通词语、只出现一次的玩笑称呼、看不出是谁的名字，都不写。
- 直播间观众的名字（被感谢送礼、SC、上舰的人，弹幕里的普通观众）不是圈内知识，不写；除非字幕说明这是大家都知道的人。
- why 用一句话说明凭什么这么判断。
- 最多 {most} 条；没有就让 items 为空数组，不要凑。

只输出一个 JSON 对象，不要任何其他文字：
{"items": [{"type": "alias 或 entity", "name": "", "of": "alias 才填：条目 id", "kind": "entity 才填：person / group / project / event / term / work / character / game / community", "why": "", "quotes": [""]}]}

最终字幕：
{lines}

这条片的弹幕和醒目留言（发送时间顺序）：
{chat}
