# 李豆沙切片标题风格（权威回灌自 .agent/skills/lidousha-title-style/SKILL.md · 2026-07-04）

这份资产是标题 LLM prompt 实际注入的**完整权威**。规则与 few-shot 都以此为准（SKILL 只读，改动回灌到这里）。

## 核心原则

观众不是因为内容点进来的，是因为**这是李豆沙**才点进来的。标题首要围绕李豆沙本人——她的气质、反应、口癖、梗、名字；切片内容只是辅助素材，用来支撑一个"关于李豆沙"的吸引人标题。引人注目为先。

判别法：把标题里的"李豆沙/主播/她"换成任何别的主播还成立的，就是失败的内容摘要式标题。

## 第零条铁律

**Ivan 给定的标题就是定稿，一字不改。** LLM 起标题只用于没有人工标题的场合。机制上：`title_llm_call=None` 时标题原样直通；前缀 / 长度 / 违禁词强制**只作用于 LLM 自动生成的标题**，绝不动人工标题。（已犯过一次：把"反沙，不是反李豆沙！"改写成别的——不许再犯。）

## 档案标题 vs 封面嵌字（Ivan 2026-07-04 明确，务必区分）

两处标题风格不同，不要混用：

- **档案标题**（B站视频页标题，带 `【李豆沙】` 前缀）：可用冒号"引语：反应"结构（历史真例"李豆沙第999次澄清：我不是奶皮！"就有冒号）。下面结构谱系 §1 的冒号结构**仅适用于档案标题**。
- **封面嵌字**（叠在封面图上的字，**不带** `【李豆沙】`）：**从不用冒号**！分句用**换行**，不用标点。真例：`唱完《旅行的意义》\n才发现伴奏像KTV录的`、`吵闹小李新哭哭表情`、`熊猫头提醒你用电安全`。生成封面向标题时就该干脆短、无冒号、常带 熊猫头/小李 等 persona 词（代码 `_lidousha_cover_text` 会把冒号自动转成换行）。

## 结构谱系（每种配语料真例；§1 冒号结构仅限档案标题）

1. **引语 + 冒号 + 她的反应**（档案标题最高频结构，**封面嵌字不用冒号**）
   - "晚安主人"现场接梗，主播立刻反杀：虽然不是你的主人
   - 被说开组会来晚了，主播反怼：因为我们还没开始唱
   - "李不是李姐？"小李疯狂吃醋：你只能看我
2. **悬念问句 + 反转/破防**
   - 迎着台风去爬山？主播当场破防：我可害怕（原真例用"直接"，2026-07-06 起禁用，示例已按新规改写）
   - 这是真猫？！结果越看越离谱，主播当场看傻
   - 花 2000 还是 2 块？豆沙当场被弹幕'上了一课'
3. **夸张宣言 / 计数 / 嘴硬**
   - 李豆沙第999次澄清：我不是奶皮！
   - 一个月没直播还嘴硬：我七月其实播了38场！
   - 我在这里是小皇帝？主播突然开始自封了
4. **名字/词语谐音梗**（优先级很高）
   - 反沙，不是反李豆沙！（Ivan 亲定）
   - 你说李登山和李洞莎是"自演婚姻"时，已经暴露了年龄歧视
5. **过程 + 意外结果（越X越Y）**
   - 开播五分钟疯狂找"猪鼻"结果越整越像猪，主播当场破防：太猪了！
   - 老师每天都在干嘛？越聊越像奇怪社会观察，最后拐到鱿鱼爱好者
6. **一本正经 + 荒谬**
   - "跳闸难道不是把闸搬上去就行了吗？"主播一本正经犯傻
   - 主播自封"女同研究学者"，还一本正经写论文
7. **歌切专用**（完整前缀"【李豆沙】豆沙歌，"）
   - 【李豆沙】豆沙歌，《宝贝》哄你睡觉 / 【李豆沙】豆沙歌，吵闹熊猫头的《嘉宾》
   - 《歌名》+翻车细节：《虫儿飞》翻车成《冲而飞》？主播唱到满屏幻听笑点 / 《又三郎》唱到一半歌词卡死，主播当场认输
8. **温柔面（哄睡/晚安类）**——**要具体到唱了什么、怎么个温柔法**
   - 温柔《虫儿飞》清唱甜美哄睡（✅ 具体；不要写成"哄睡到犯规"这种空洞万能后缀）
   - 观众想在直播间睡觉，她细声细气念晚安名单

## 高频词库（她的气质抓手）

当场、直呼、突然、疯狂、破防、翻车、犯傻、嘴硬、嘴瓢、认输、看傻、吃醋、反杀、反怼、整活、自封、澄清、一本正经、越X越Y、结果、还、太X了

专属名词：李豆沙、豆沙、小李、主播、熊猫头、侄女、kmx、长沙话（详见 `assets/lidousha/persona.md` 与 `glossary.txt`）

## 硬性规范

- **发布到 B 站的标题一律加前缀【李豆沙】**（Ivan 2026-07-04 明确：这是规范，不分谈话/歌切；频道全量视频均如此）。**歌切完整前缀是"【李豆沙】豆沙歌，"**。构思/内部记录时可不带前缀，投稿时必须带；Ivan 给定的标题若未带前缀，发布时补前缀、正文一字不改（例："反沙，不是反李豆沙！"→"【李豆沙】反沙，不是反李豆沙！"）。**字数按含前缀计。**
- **12–30 字**，口语化、有画面感。
- 引号引她的原话或弹幕原话；冒号引出反应/后半句（仅档案标题）；？！制造悬念。
- 标题里引用的话必须真实出现在切片里（可轻度精炼，不许编造）。

## 违禁词（LLM 自动标题命中即重写，仍不合格则打 flag 保留）

**6 个空洞标题党词，一律禁用（作为独立词）：炸裂 / 震惊 / 天花板 / 绝了 / 犯规 / 太顶。** 这类空洞夸张词 Ivan 不喜欢。

**「直接」全局禁用（Ivan 2026-07-06）**：标题里绝不出现"直接"这个弱化词——"直呼打咩"比"直接打咩"好得多；用 直呼/当场/秒X 替代。

**离谱是两用词**：描述性的"越看越离谱 / 越整越离谱"是 Ivan 认可的结构（见 §2/§5 真例），可以用；只有空洞的 **"X到离谱"后缀式**才禁。

更禁 **"X到犯规/炸裂/离谱"这种万能后缀**——它把任何东西都套成夸张，却不说清到底发生了什么。标题必须**具体到发生了什么**。

- 2026-07-04 精修实例：虫儿飞"哄睡到犯规"被 Ivan 否 → 应写"温柔《虫儿飞》清唱甜美哄睡"这种具体描述。

## 反例（不要这样起）

- ❌ "关于AI图像相似度的讨论"（内容摘要，无她）
- ❌ "太炸裂了！你绝对想不到发生了什么"（泛泛标题党）
- ❌ "主播看图评论合集"（无反应、无气质、无梗）
- ❌ "哄睡到犯规"（"X到违禁词"万能后缀，不具体）→ ✅ "温柔《虫儿飞》清唱甜美哄睡"
