# 示范写法（模板）

这里放你的频道真实发过、效果好的标题，按落点写法分组；每条后面可以用「——」注明用的称呼和张力（注释不属于标题）。
还没有真例时先留下面几条写法说明，攒到真例后替换。别的频道的例子不要放进来：模型会照着例子写。

## 标题，按落点写法分

1. 粉丝或主播本人口吻的吐槽、感叹收尾：先写片里发生的那件具体的事，再接一句取自片里的吐槽或感叹。
2. 原话直接当主体：她最嘴硬或最荒诞的那句原话，连同让它好笑的那半句转折；看不出在说哪件事时前面加几个字交代。
3. 问句、反问：写出具体的人和事，把结果留成悬念。
4. 判词、谐音梗、短标签：一句话下判断，或用片里已有的谐音和叫法。
5. 长一些的：每个分句都加新事实或新笑点时才这样写。

共同点：没有冒号；一个落点；有张力；称呼一条只用一种。

## 常见错误

| 错 | 对 |
|---|---|
| 前因，主播强调/急着自证/还说……（旁白转述） | 换成她本人或粉丝的口吻收尾 |
| 前因：原话（冒号引出） | 原话用逗号接上，或直接让她的话当主体 |
| 先……又补一句……再……（把经过讲完） | 只留一个落点；长标题每个分句都要加新事实或新笑点 |
| 如何看待某事（只有话题） | 写出具体发生了什么 |
| 只有梗名、没有前因 | 点名，交代前因 |
| 一条里混用两种称呼，像两个人 | 按场景换称呼，一条只用一种；主语明确时可不写 |
| 封面字只剩主题标签 | 封面字用她的真实反应 |
| 无字截图做封面 | 任何截图都要加封面字 |
