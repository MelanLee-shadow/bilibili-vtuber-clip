**长短是伪命题。** 本频道 2026-06/07 谈话切片 n=69：短(≤13字)/中(14-25)/长(>25) 中位播放 720/561/529——差距远小于题材差距。Ivan 三拍叙事长标题里既有 1981（迷魂阵「我是侄女啊」）也有 202（拜早年）；生态短爆点同理。

## 二、封面：生态语法 vs 我们的差距

20万+ 播放封面的共同语法（40 张目检）：

1. **真实名场面表情**（Live2D/3D 截图原味）而非精修重绘——60.1万北影教材=纯礼墨臭脸大特写零文字；31万 kiss kiss=害羞嘟嘴大头贴零文字；29.1万提拉苏米=低头俯拍名场面截图。
2. **字=2-12 字梗字，从不是整条标题**——34.4万橘番怒吼封面字是"给我整无语了"（她的原话，≠标题）；28万纯文字封面两档字（红小字"女电话本注意⚠"+橙巨字"什么是直女"）；27.5万礼墨"一蹦一跳/尽显巨X本色"两条旋转贴纸字。
3. 暖色巨字+粗白描边、可旋转、meme 贴纸味；黑/平色底可承纯文字盘点类；emoji/遮字（⚪X？）作钩子。
4. 脸大：高播放封面脸部占画面 50-90%。

我们的自动封面（对照）：插画精修质量高，但**整条 30-46 字标题搬上封面**（灯案 5 行字墙 137px、花篮 7 行、"李豆/沙"拆名断行），feed 缩略图下不可读；这是 2026-07-10「保留完整标题靠多换行放大」旧规的直接后果。

## 三、已落地的改动（214b3b2 + 本次）

1. **封面梗字模式（cover_punch）**：自动标题封面默认改为 1-2 行梗字——艺术指导 LLM 从文案挑「她最出圈的一句」（main 2-12 字整行 hook 色 + 可选 sub 副行奶油色半号；逐字可溯源，编造即拒）；确定性兜底取最后一个 ！/？ 短分句；都没有→回退整段旧行为（fail-open）。
2. **梗字封面强制 banner 全宽文字区**：窄边栏里 9 字梗字只有 ~82px（比旧字墙还小）；banner 下同字 165px。CPA 构图 prompt 与叠字 zone 随 layout 统一。
3. **边界**：Ivan 手定标题封面不走梗字（仍守 2026-07-06「每个成分都不许丢」铁律）；歌切仍是裸《歌名》banner；表情包 replace 通道与梗字天然兼容。
4. **标题侧**：题材优先级实证规则写进 title_style.md（身份钩子 front-load / 冷梗降权 / 歌切配额维持）。

## 七（2026-07-21 追加）、封面三路线路由器 + 截图轻微调落地

Ivan 拍板："截图微调以达到更好效果" + "加入判断哪些切片适合全图 CPA 重做、哪些适合截图"。落地：

**三路线**：`screenshot_direct`（真名场面原味+梗字，零 CPA）／`screenshot_polish`（新增：选帧裁切 → gpt-image-2 **逐像素保真修图**——只清直播 UI 杂物（弹幕框/SC/歌单字/字幕字）+ 修画质，禁止改姿势表情构图 → 叠梗字；失败降级直出）／`cpa_redraw`（原全图插画重绘）。

**路由判据**（`_decide_cover_treatment`，AUTOSLICE_COVER_MODE=auto 为新默认，可用 screenshot/polish/cpa 强制）：
- 歌切 / Ivan 手定标题 / 选帧失败 → cpa_redraw（唱歌净美学 / 成分不丢铁律）
- 名场面分 ≥4.5（或 ≥3.2 且命中情绪字幕段）→ 直出：真表情就是封面
- ≥2.6 → 轻微调：构图可用但需清杂物修画质
- 更低 → 全图重绘：没有好瞬间，插画承载力更强
- 阈值标定自 17 条本地成片修正后的分数分布；本地实测路由 5 直出/7 轻微调/5 重绘。

**片头假峰修复**：z1-budui 片头实测 5749ms > 旧固定 skip 5000ms，过渡帧整屏 diff 制造假峰（平静脸拿 8.13 分）。双保险：①生产从 record `burned_preview.branding_intro.intro_offset_ms` 权威取值 +1.5s settle；②选帧器内置前 9s >8×中位的切点探测兜底（独立运行/老 record 也安全）。

**真链路验证**（凭据取自 free，gpt-image-2 真实修图）：百合算法片（3.50→轻微调）修图后 SONG LIST/弹幕框/字幕全清、姿势表情逐像素保真、月海画质全面提升；捏秦（5.09→直出）、拉拉（3.20→轻微调）均一次通过。1587 测试全过。
