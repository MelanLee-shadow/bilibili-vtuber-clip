# 李豆沙切片标题风格

适用：为李豆沙（B站虚拟主播，房间 22966160）的切片起标题、审查/修改标题、或配置标题生成 prompt 时。语料：Ivan 全部历史成片标题（85+ 条，收割自 free 生产 publish.json，few-shot 精选见 `assets/lidousha/title_style.md`，标题 LLM prompt 注入用的就是那份资产）。

## 第零条铁律

**Ivan 给定的标题就是定稿，一字不改。** 他说"标题可以取为 X"，X 就是最终标题，不是风格参考。机制上：`_stage_publish_draft` 传 `title_llm_call=None`，标题原样直通。LLM 起标题只用于没有人工标题的场合。（已犯过一次：把"反沙，不是反李豆沙！"改写成了别的——不许再犯。）

## 核心原则（Ivan 2026-07-03 原话转述）

观众不是因为内容点进来的，是因为**这是李豆沙**才点进来的。标题首要围绕李豆沙本人——她的气质、反应、口癖、梗、名字；切片内容只是辅助素材，用来支撑一个"关于李豆沙"的吸引人标题。引人注目为先。

判别法：把标题里的"李豆沙/主播/她"换成任何别的主播还成立的，就是失败的内容摘要式标题。

## 档案标题 vs 封面嵌字（Ivan 2026-07-04 明确，务必区分，我曾混淆）

**两处标题风格不同，不要混用：**
- **档案标题**（B站视频页标题，`【李豆沙】`前缀）：可以用冒号"引语：反应"结构（历史真例"李豆沙第999次澄清：我不是奶皮！"就有冒号）。下面结构谱系 §1 的冒号结构**只适用于档案标题**。
- **封面嵌字**（叠在封面图上的字，不带`【李豆沙】`）：**从不用冒号**！分句用**换行**，不用标点。真例：`唱完《旅行的意义》\n才发现伴奏像KTV录的`、`吵闹小李新哭哭表情`、`熊猫头提醒你用电安全`。代码 `_lidousha_cover_text` 已把冒号自动转成换行——但生成标题时封面向的就该直接无冒号、短、常带 熊猫头/小李 等 persona 词。

## 结构谱系（每种配语料真例；§1 冒号结构仅限档案标题）

1. **引语 + 冒号 + 她的反应**（档案标题最高频结构，**封面嵌字不用冒号**）
   - "晚安主人"现场接梗，主播立刻反杀：虽然不是你的主人
   - 被说开组会来晚了，主播反怼：因为我们还没开始唱
   - "李不是李姐？"小李疯狂吃醋：你只能看我
2. **悬念问句 + 反转/破防**
   - 迎着台风去爬山？主播直呼：我可害怕（原例含禁词，已清洗）
   - 这是真猫？！结果越看越离谱，主播看傻了
   - 花 2000 还是 2 块？豆沙被弹幕'上了一课'
3. **夸张宣言 / 计数 / 嘴硬**
   - 李豆沙第999次澄清：我不是奶皮！
   - 一个月没直播还嘴硬：我七月其实播了38场！
   - 我在这里是小皇帝？主播突然开始自封了
4. **名字/词语谐音梗**（优先级很高）
   - 反沙，不是反李豆沙！（Ivan 亲定）
   - 你说李登山和李洞莎是"自演婚姻"时，已经暴露了年龄歧视
5. **过程 + 意外结果（越X越Y）**
   - 开播五分钟找"猪鼻"结果越整越像猪，主播直呼：太猪了！
   - 老师每天都在干嘛？越聊越像奇怪社会观察，最后拐到鱿鱼爱好者
6. **一本正经 + 荒谬**
   - "跳闸难道不是把闸搬上去就行了吗？"主播一本正经犯傻
   - 主播自封"女同研究学者"，还一本正经写论文
7. **歌切专用**
   - 豆沙歌系列：【李豆沙】豆沙歌，《宝贝》哄你睡觉 / 【李豆沙】豆沙歌，吵闹熊猫头的《嘉宾》
   - 《歌名》+翻车细节：《虫儿飞》翻车成《冲而飞》？主播唱到满屏幻听笑点 / 《又三郎》唱到一半歌词卡死，主播只好认输
8. **温柔面（哄睡/晚安类）**
   - 观众想在直播间睡觉，她直接温柔到让你梦里也看得到她

## 高频词库（她的气质抓手）

直呼、甚至、终于、大大方方、反向、到底、万一、早就、只好、一定要、太…了、瘾来了、假装不知情、逆出道、没有边界感、奇遇记、精选辑
（**词库来源铁律（Ivan 2026-07-06）**：只允许收录经 Ivan 已上传/手定标题验证过的词；free 生产线机器生成的旧标题**不是语料**——此前词库混入了 当场/疯狂/破防/看傻 等机器词，Ivan 从未用过，已清除。扩词先对照已上传标题。）

专属名词：李豆沙、豆沙、小李、主播、熊猫头、侄女、kmx、长沙话（详见 `assets/lidousha/persona.md` 与 `glossary.txt`）

## 硬性规范

- **发布到 B 站的标题一律加前缀【李豆沙】**（Ivan 2026-07-04 明确：这是规范，不分谈话/歌切；频道全量视频均如此）。构思/内部记录时可不带前缀，投稿时必须带；Ivan 给定的标题若未带前缀，发布时补上前缀、正文一字不改（例："反沙，不是反李豆沙！"→发布为"【李豆沙】反沙，不是反李豆沙！"）。字数限制按含前缀计。
- 12–30 字，口语化、有画面感
- 引号引她的原话或弹幕原话；冒号引出反应/后半句；？！制造悬念
- 禁：**机器味弱化/强调词「直接」「当场」「秒X」**（Ivan 2026-07-06：他的真实历史标题从未有过这些；"直呼打咩">>"直接打咩"；代码 `_TITLE_BANNED_FILLER_WORDS`+`_TITLE_BANNED_MIAO_RE` 硬门）
- 禁：泛泛标题党词（炸裂/震惊/天花板/绝了/**犯规**/太顶全局禁；**离谱是两用词**——描述性"越看越离谱"是 Ivan 认可的结构可以用，只禁空洞的"X到离谱"后缀式，见 `_TITLE_SUFFIX_ONLY_HYPE_WORDS`）、纯内容摘要、书面语。这类空洞夸张词 Ivan 不喜欢——标题要具体到发生了什么，不用"X到犯规/炸裂"这种万能后缀（2026-07-04：虫儿飞"哄睡到犯规"被否，应是"温柔《虫儿飞》清唱甜美哄睡"这种具体描述）。
- 标题里引用的话必须真实出现在切片里（可轻度精炼，不许编造）
- **Ivan 定稿标题的每个成分都是有意的，封面短句化时一个都不许丢**（2026-07-06：封面漏掉"22966160"被指正——那是直播间自称，是标题有机部分。数字/房间号/自称类成分照搬原样；ASCII 串是排版原子不拆行）。
- **讨论某部作品的切片，标题必须带上《作品名》**（作品名从转写/弹幕确证，不许猜；2026-07-06 Ivan 明确）

## 反例（不要这样起）

- ❌ "关于AI图像相似度的讨论"（内容摘要，无她）
- ❌ "太炸裂了！你绝对想不到发生了什么"（泛泛标题党）
- ❌ "主播看图评论合集"（无反应、无气质、无梗）
